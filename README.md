# 🧠 Breast Cancer Detection using SVM

A Machine Learning pipeline for detecting **benign vs malignant breast tumors**
from mammogram images using Support Vector Machines (SVM),
advanced preprocessing, PCA, and ensemble techniques.

---

## 🚀 Highlights
✅ End-to-end ML pipeline  
✅ Automated dataset organization  
✅ Feature engineering  
✅ PCA dimensionality reduction  
✅ Hyperparameter tuning  
✅ ROC & Confusion Matrix visualization  
✅ CLI prediction system  
✅ Reproducible training
